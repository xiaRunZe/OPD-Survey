## 📝 新论文录入流程

### Step 1: 找到论文

来源 → 论文标题/链接 → 下载 PDF

### Step 2: 快速阅读

读以下 4 个部分：
1. **Abstract** —— 解决什么问题
2. **Introduction** —— 现有方法不足
3. **Method** —— 核心方法
4. **Experiments** —— 关键结果

### Step 3: 分类归入

参考 README 分类，决定属于哪个章节：
- 综述 / 白盒 / 黑盒 / OPSD / 迭代 / OPD-RL / 推理 / 多模态 / Agent / 投机 / 框架 / 工业

### Step 4: 撰写中文解读

按统一格式：

```markdown
## [序号]. [论文标题]

| 项目 | 内容 |
|------|------|
| **作者** | XXX |
| **机构** | XXX |
| **时间** | YYYY-MM |
| **会议/期刊** | XXX |
| **arXiv** | [XXXX.XXXXX](link) |
| **代码** | [链接](URL) |

### 🎯 动机
（2-3 句话，说清"为什么"和"现有方法不足"）

### 💡 方法思路
（3-5 句话，包含核心公式、算法流程、白话解释）

### 📊 效果
（关键 benchmark 和对比）

### ⚠️ 局限
（方法的不足之处）
```

### Step 5: 更新 daily-updates

在 `daily-updates/YYYY-MM-DD.md` 中记录：
- 当天新增论文数
- 重要发现
- 待办事项

### Step 6: 更新 README.md 索引

如新论文增加新的子分类，更新 README 目录。
